# 🌌 Starward Space - 架构设计白皮书

本文档记录 Starward Space（星向空间）的整体架构演进路径、技术规范与安全边界。

---

## 1. 核心技术栈矩阵

| 分层 | 技术选型 | 版本/规范 | 选型理由 |
| :--- | :--- | :--- | :--- |
| **运行时 (Runtime)** | OpenJDK | 21 (LTS) | 现代 Java 长期支持版，具备虚拟线程与前沿特性 |
| **后端框架** | Spring Boot | 3.3.x | 工业级主流脚手架，与 Java 21 原生契合 |
| **持久层 ORM** | MyBatis | 3.0.x | 灵活可控，严格使用 `#{}` 参数化预编译防 SQL 注入 |
| **关系型数据库** | MySQL | 8.4 LTS | 本地原生常驻运行，稳定、可靠、轻量占用 |
| **缓存与限流** | Redis | 7.x | 热度排行榜、IP 访问频控、点赞计数 |
| **前端交互** | Vue 3 + Vite | 3.x | 现代化响应式框架，极致构建速度与毛玻璃 UI 组件化 |
| **样式与动效** | Tailwind CSS | 3.x / 4.x | 原子化实用类，毛玻璃（Glassmorphism）与暗黑主题切换 |
| **反向代理 & 防火墙** | Nginx | 1.24+ | 目录遍历防御、隐藏路径拦截、403 熔断 |

## 2. API 响应标准化协议

全站所有 RESTful 接口严格遵循统一的 JSON 包装体：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { ... },
  "timestamp": 1790228123456
}
```

- **200**：请求成功（Success）
- **400**：参数校验失败（Bad Request）
- **401**：凭据无效或未登录（Unauthorized）
- **403**：权限不足（Forbidden）
- **404**：目标资源不存在（Not Found）
- **500**：系统内部异常（Internal Server Error）
